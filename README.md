# Green Decoupling Python Framework
## Cluster Analysis of Structural Heterogeneity in EU Economies

**Author:** Zlatko Čehulić

This repository contains a data science framework developed in **Python (Jupyter Notebook)** for analyzing structural heterogeneity across EU economies concerning **Green Decoupling** (the separation of economic growth from environmental pressure).

This project demonstrates applied macro-statistical modelling and clustering analysis using EU data. It is a partial replication and extension of research presented at the **ICED Conference (December 2025)**.

---

## Skills and Relevance

- **Programming:** Python (Pandas, Scikit-learn, Matplotlib)
- **Statistical Indicator Development:** Calculation of $\beta_{GHG}$ (Emissions Elasticity to GDP)
- **Advanced Quantitative Analysis:** K-Means Clustering (Demonstrates sound analytical and quantitative skills)
- **Climate-Related Issues:** Focus on emissions analysis and decoupling regimes (Relevant for ECB Climate Centre)
- **Data Handling:** Processing and structuring macro-statistical data for EU-27

---

## Repository Structure

- `Green_Decoupling_Cluster_Analysis.ipynb` – Core analysis, data loading, clustering implementation, and visualization.
- `README.md` – Project overview and technical documentation.
- `requirements.txt` (Optional) – List of required Python libraries.
- **Output:** The Notebook contains the final scatter plot showing identified clusters (High-decoupling vs. Low-decoupling).
